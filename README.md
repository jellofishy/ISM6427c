# Weather

A responsive weather app using the free, keyless [Open-Meteo](https://open-meteo.com/) API.
Defaults to Boca Raton, FL. Light, dark, and system themes. Plain HTML/CSS/JS — no build step.

## Run locally
Open `index.html`, or run `npx serve .`

## Deploy to Netlify
Connect this repo in Netlify (no build command; publish directory `.`, set by `netlify.toml`),
or drag the folder into https://app.netlify.com/drop.
